# Data Files and Reproducibility Boundary

## Git LFS

The three large CSV files under `processed/` are tracked by Git LFS. After cloning, run:

```bash
git lfs pull
git lfs ls-files
```

Do not analyze a file whose first line is `version https://git-lfs.github.com/spec/v1`; that is an unresolved pointer rather than the dataset.

## Reference data

- `reference/biorxiv_token_probabilities.parquet`: token-probability table consumed by the maximum-likelihood estimator.
- `reference/country_epi.tsv`: country-level English Proficiency Index table used in figure-data preparation.
- `reference/country_language_type.tsv`: country language-family classification used in figure-data preparation.

The original material package did not provide complete source citation, version, construction, or license metadata for these reference files. Their contents are preserved without modification. Users should not infer that the repository MIT License applies to these third-party data. Complete provenance should be supplied in a future release when the original records are available.

## Processed analysis data

- `processed/paper_level_analysis.csv`: paper-level input for the event-study, DiD, DDD, and country analyses.
- `processed/first_author_analysis.csv`: first-author-level input.
- `processed/last_author_analysis.csv`: corresponding/last-author-level input.

These files preserve the supplied analysis snapshots. Dates were removed from active filenames because release versions should be identified through Git commits and repository releases.

The source package did not include the study-specific code or all upstream source tables needed to join AI-usage estimates with bibliographic, author, journal, institution, and country attributes. The processed datasets are therefore the reproducible starting point for the statistical and figure notebooks; they are not currently regenerated by the PMC collection and estimation scripts.

## Raw and intermediate data

Raw PMC XML and generated intermediates are intentionally excluded through `.gitignore` because of size and article-level licensing constraints:

- `raw/pmc/`
- `interim/pmc/`
- `interim/ai_usage/`

`code/data_collection/download_pmc_cloud.py` retrieves explicit, reusable PMC article versions from the official NLM AWS dataset and writes an acquisition manifest containing source, version, license, and checksum information. The original raw archive snapshot and exact article-version list were not included in the supplied materials.
